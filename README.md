# Password Bridge — macOS ローカル移行アプリ v0.2.0

Apple「パスワード」のCSV比較と、複数保管庫のログイン整理を支援するSwiftUIアプリです。0.2.0は全画面で読み取り専用です。Security Cleanupの使い方と設計は [docs/SECURITY-CLEANUP.md](docs/SECURITY-CLEANUP.md) を参照してください。秘密情報はアプリの作業ファイルへ保存せず、メモリ内で処理します。1Passwordとの通信・同期は公式CLIが行います。解析やテレメトリー送信機能はありません。

## 起動

Command Line ToolsとSwift 6を用意し、次の手順で `Password Bridge.app` を作成して開きます。生成したアプリやビルドキャッシュ、パスワードのエクスポートはGit管理に含めません。ビルドしたMac向けのローカルアプリで、Developer ID署名・公証はしていません。

```sh
./build-app.sh
open "Password Bridge.app"
```

## 使い方

1. 「サンプルを見る」で判定画面を確認します。サンプルを実際の保管庫へ移行することはできません。
2. Apple「パスワード」でパスワードをCSVとして書き出し、「Apple CSVを開く」で選びます。UTF-8のTitle, URL, Username, Password, Notes, OTPAuth列に対応。未知の列・壊れたCSVは情報を落とさないため拒否します。
3. 1Password CLI 2を別途インストールし、1Passwordの設定でCLI連携を有効にします。CLIの絶対パス、アカウントID、保管庫IDを入力し、「読み取り・再比較」を押します。IDは `op account list` と `op vault list --account アカウントID` で調べられます。CLIの場所は `which op` で確認します。
4. Apple CSV比較タブで既存の比較結果・候補の詳細を確認します。0.2.0では読み取り専用の要件に合わせて移行ボタンと実行処理を無効にしています。過去の新規登録用CLIコードは残っていますが、画面からは呼び出しません。
5. 一致項目のチェックリストを保存できます。1Passwordで実際のログイン、TOTP、未移行のパスキー、共有状態、付随情報を確認し、Appleアプリで手動削除します。チェックリストにもサイト名・ユーザー名が含まれるため適切に保管してください。
6. 作業後「データを閉じる」でアプリ内の参照を解放します。元CSVは自動削除しません。平文ファイルのバックアップ・同期先を含めて保管・削除を確認してください。Swiftのメモリの完全消去を保証する機能ではありません。

比較用CSVだけを読み込んだ場合はプレビュー専用です。この版ではライブ接続しても書き込みは実行できません。他の保管庫は比較しません。対象保管庫は個人用の非共有保管庫を推奨します。

## 判定と制限

- 同一URLとユーザー名でパスワードが違う場合は競合。更新日で新旧を推測せず、上書きしません。
- URLはホストとスキームの大文字小文字、末尾のルートスラッシュのみ正規化。サブドメイン、パス、ユーザー名の大文字小文字は保持します。同じホスト上のパス・方式やIDの大文字小文字が異なる項目は、関連候補として表示します。関連候補は新規登録しません。サブドメインや別ドメインの関連推測は未対応です。
- タイトルは比較判定に含めません。秘密・メモが同じでも名称は異なる可能性があります。
- Apple CSV内の完全重複は別表示し、内容が異なる重複は競合にします。
- 0.2.0は新規作成も無効です。既存項目の編集・統合・削除もありません。パスキーを含む既存項目をJSONで更新すると消失する可能性があるため、編集処理は設けていません。
- 登録・照合失敗時は停止。登録だけ成功した可能性があるため、再比較してから続けてください。再比較で重複を抑制しますが、別アプリが同時に書き込む競合までは防げません。
- チェックリストは削除の承認書ではありません。Apple CSVに出ないパスキー・Wi-Fi・履歴・共有状態、1Password独自フィールドは検証対象外です。Apple側の削除はiCloud同期先にも影響します。
- パスキーの公式転送対応の実機確認・再登録ガイド、暗号化セッション保存、複数保管庫の横断比較、自動削除は今後の対象です。
- 読み取りは50項目ずつ最大3並列で取得します。取得済み件数・経過時間・残り目安を表示し、中断できます。各CLIコマンドは120秒でタイムアウトします。認証待ちも含む上限です。中断・失敗時の部分結果は採用しません。

## 検証

`swift run BridgeChecks` でCSVの引用符・改行・秘密の空白保持、不正入力拒否、競合、重複、保守的なURL照合を検証します。実アカウントの読み書きは利用者の認証後に行います。実際の秘密データでのエンドツーエンド検証は未実施です。

## 0.1.1 性能修正

画面の再描画ごとの比較実行を廃止し、データ変更時にのみ比較結果を更新します。Apple内の競合確認はURL・IDごとの索引で候補を絞ります。CSVの読み込み・解析は画面処理と別に実行します。架空データ10,000件の空の比較先との照合テストを追加し、デバッグビルドで約0.10秒、全8テスト群が成功しました。実際の利用者CSVはテストに使用していません。

## 0.1.2 読み取り高速化

公式CLIの標準入力による複数項目取得に変更し、50件を1つのプロセスで取得、最大3プロセスを並列実行します。123件の模擬保管庫の取得が3回のget呼び出しで完了することをテストしました。実際の保管庫での時間短縮率は未測定です。取得完了件数は50件単位（最後は残件数）で更新されます。認証待ち・CLIの内部処理は外部から区別できないため、一覧取得中は認証画面の確認を案内します。

進捗、中断、タイムアウト、欠落・重複IDの検出を追加。中断はこの操作に属するCLIだけを停止し、途中結果を破棄します。必要なら1秒後に強制停止します。登録操作は中断ボタンの対象外です。模擬CLIによる一括取得・欠落・非ゼロ終了・中断・タイムアウトと既存の比較検証を含め、全9テスト群が成功しました。実アカウントへの接続や書き込みは検証に使用していません。

## 0.1.3 CLI応答のJSONストリーム対応

複数項目の応答を単一JSON配列と仮定していた読み取り処理を修正しました。JSON配列、単一オブジェクト、改行・空白で区切られた複数JSONオブジェクト（複数行整形を含む）に対応します。文字列内の括弧やエスケープを区別し、末尾の欠損・不正データも検証します。CLIの生の出力・秘密情報はエラーに含めません。模擬CLIも整形済みJSONの連続出力に変更し、123件の一括取得を含め全10テスト群が成功しました。実保管庫での再検証は利用者側で行います。

## 0.1.4 関連候補と確認画面

AppleのトップURLと1Passwordの `/login` などのパス差、HTTP/HTTPS差、同一ホスト上のユーザー名の大文字小文字差を関連候補として検出します。同一アカウントと断定せず、自動登録・統合の対象から外します。判定理由と候補を「詳細」で確認でき、パスワード・TOTP設定・メモは内容自体を表示せず一致・差分を表示します。別ホストや別ユーザー名を同一視しません。

一覧を50件単位のページ表示にし、判定別フィルターと検索を併用できます。1件ずつのチェックをボタンに変更し、このページの候補のみを一括選択できます。選択はページをまたいで保持し、全体の選択件数を表示、「選択を解除」で全解除します。再取得・データ変更時は先頭ページに戻ります。

合成したURL・ユーザー名の差分例で、既存項目を新規候補にしないこと、異なるホストや別ユーザーを混同しないことを検証しました。利用者の実データはテストに使用していません。

## 0.1.5 一覧の並べ替え

タイトル・URL・ユーザー名・判定・理由の列見出しをクリックして昇順・降順を切り替えられます。初期表示はタイトル順です。検索・判定フィルターの対象全件を並べ替えてから50件ごとに表示します。並べ替えると先頭ページに戻り、チェックした項目はIDで保持します。列そのものの左右の配置変更は未対応です。

## 0.2.0 Security Cleanup

複数保管庫のLOGINのみを読み取り、ローカルで再利用グループ・重複候補・簡易強度を分析します。重要分類の優先表示、6種類の対応状態、ローカルの記録保存、再取得前後のリスク要約の比較に対応します。表示は全件スクロールで検索・リスク別フィルターを併用できます。生の秘密・秘密のハッシュを表示モデルや記録に残しません。Swiftのメモリ消去を保証するものではありません。

Watchtowerの漏洩判定は公開CLI仕様で取得方法を確認できないため未対応です。外部APIへの照合・パスワード送信は行いません。アプリ内の既存移行操作も無効にしました。詳細な設計、判定の限界、公式資料、テスト内容は [Security Cleanupの説明](docs/SECURITY-CLEANUP.md) に記載しています。
